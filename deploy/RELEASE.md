# v0.10.0 個人化風格、頭像與公告評論

- 修正公告作者頭像偏移及深色公告文字對比。
- 個人化設定提供 7 種風格、頭像上傳、暱稱，集中保存在帳號資料中。
- 名稱顯示保留原名並附加括號暱稱；頭像套用於帳號、公告作者與評論。
- 公告張貼者與管理員可開關評論區，關閉後保留原有評論。
- 評論依公告對象檢查權限，評論者、公告張貼者與管理員可刪除評論。
- 上方新增 GitHub repo 按鈕。

- 建立及編輯帳號可勾選登入時要求更換密碼、停用帳戶。
- 所有帳號可建立後再編輯登入名稱、姓名、狀態與密碼；管理員可調整角色，教師可編輯學生。
- 強制換密碼由 API 控制，完成前不可讀寫一般資料；完成後更新登入憑證並撤銷其他登入。
- 停用及帳號編輯會撤銷既有登入；保留原密碼與明確重設密碼分開操作。
- 自己不能停用自己，至少保留一名啟用中的管理員；資料庫新增欄位保留既有帳號。
