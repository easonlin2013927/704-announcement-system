# v0.11.0 部落格式公告編輯工作室

- 學生、教師與管理員頁首統一顯示「班級公告」。
- 全新公告編輯版面：大標題、寬敞寫作區與發布設定側欄。
- 可切換撰寫及閱讀預覽，預覽顯示標題、分類、對象和格式化內文。
- 專注寫作模式、即時字數、閱讀時間、自動摘要及標題大綱。
- 富文字工具新增復原與重做；發布期間停用提交按鈕，減少重複送出。
- 編輯頁支援窄螢幕單欄排列與七種個人化風格。內容須按發布或儲存才會保存。
- 個人化設定提供七種風格、帳號頭像與暱稱，儲存於雲端帳號。
- 公告可選擇開啟評論；留言會顯示作者頭像、暱稱，並依權限管理。
- 修正公告作者頭像對齊及文章文字對比。
- 新增系統頁首 GitHub 專案連結。
