## v0.14.0 班級生活功能

- **作業簿**：管理員建立科目；教師與小老師可分日期登錄多項功課、各設截止日，預設全班，也可指定學生。學生可勾選自己的完成紀錄。
- **缺交與個別評語**：教師或管理員勾選學生新增紀錄，在當事學生首頁及「我的提醒」顯示，可標記已補交。
- **學生聊天**：學生可私訊、自建群組、加入成員、退出群組、收回或檢舉訊息；管理員可停用聊天及處理被檢舉訊息。
- **行事曆**：整合作業截止日、活動開始與結束時間，以及各使用者自己的代辦事項。
- **新增選單**：補上作業、缺交、評語、個人事項，修正捲動時浮在導覽列上方的問題。

閱讀[學生操作手冊](docs/wiki/Student-Life.md)及[教師／管理員手冊](docs/wiki/Classroom-Management.md)。全部資料集中保存在 PostgreSQL，不使用瀏覽器本機儲存。聊天每 5 秒更新，歷史訊息可分頁載入；目前不提供附件、已讀回條及推播通知。

GitHub Wiki：[學生班級生活手冊](https://github.com/easonlin2013927/704-class-system/wiki/StudentLife) · [教師與管理員班級管理手冊](https://github.com/easonlin2013927/704-class-system/wiki/Classroom)。

v0.12.0：頁首改用公告鈴鐺圖示。教師與管理員從「新增 → 公告」開啟部落格編輯工作室，可直接貼上截圖（Ctrl＋V）或選取圖片，網址會自動成為可點擊的超連結。圖片壓縮後隨公告保存於雲端。

v0.12.0 起，學生、教師與維護人員頁首統一顯示「班級公告」。新增[個人化設定](docs/wiki/Personalization.md)：7 種風格、上傳頭像及暱稱，均保存到帳號。公告張貼者或管理員可在公告編輯頁切換評論區；讀者可以留言，顯示頭像與「原名稱（暱稱）」。上方 GitHub 按鈕可直接開啟本專案。

管理員除了教師的公告管理、富文字編輯與登入標語設定，還可建立學生／教師／管理員帳號、調整角色、刪除帳號，以及設定所有頁面頂端的跑馬公告。帳號與跑馬公告均儲存在 PostgreSQL；最後一位管理員與目前登入中的管理員帳號受到保護。詳見[管理員手冊](docs/wiki/Maintenance-Guide.md)。

教師發布富文字公告，學生登入閱讀；前端使用 GitHub Pages，後端為自架 Node.js API 與 PostgreSQL，透過 Cloudflare Tunnel 提供 HTTPS。

## 各系統登入網址

| 身分 | 登入連結 | 功能 |
| --- | --- | --- |
| 小老師 | [教師／小老師登入](https://easonlin2013927.github.io/704-class-system/#/teacher/login) | 公告與活動管理，無帳號管理權限 |
| 學生 | [學生登入](https://easonlin2013927.github.io/704-class-system/#/student/login) | 閱讀、搜尋及分類公告 |
| 教師 | [教師登入](https://easonlin2013927.github.io/704-class-system/#/teacher/login) | 發布、編輯、刪除與置頂公告 |
| 維護人員（管理員） | [維護人員登入](https://easonlin2013927.github.io/704-class-system/#/admin/login) | 公告管理、帳號管理、跑馬公告與系統狀態 |

三個登入畫面獨立，沒有跨身分切換按鈕。根網址預設進入學生登入。連結只是入口，權限由後端帳號角色決定；錯誤入口會拒絕登入，不能用網址升級權限。切換入口會清除目前登入狀態。

管理員擁有教師的公告管理與登入標語設定功能，並可建立學生、教師及管理員帳號、調整角色、刪除帳號與編輯全站跑馬公告。詳細步驟請閱讀[維護人員手冊](docs/wiki/Maintenance-Guide.md)。

## 功能與資料保留

支援粗體、斜體、底線、螢光筆、標題、引用、清單與連結。公告集中存於 PostgreSQL，沒有到期自動刪除；清除瀏覽器資料與重新部署前端不會刪除公告。教師可共同管理公告。

前端不使用 localStorage、sessionStorage 或 IndexedDB 儲存公告或登入憑證，登入憑證使用安全 Cookie 維持登入，瀏覽器阻擋跨網站 Cookie 時可能需要重新登入。沒有草稿、回收桶、附件與即時通知。資料庫仍需由維護人員定期備份。

## 開發與部署

前端使用 Node.js 22，無第三方套件依賴：

```sh
npm run check
npm run build
node scripts/serve.mjs
```

後端需安裝 server/package.json 的 pg 依賴。部署方式與主機環境變數見 deploy/README.md；不要執行舊 supabase/schema.sql。升級時必須同時更新前端與後端。

目前 API 與 Tunnel 已啟動，前版教師／學生權限已在主機實測。0.3.0 新增 admin 角色，升級會原子更新帳號角色約束，保留原有資料。

## 活動倒數（v0.10.0）

教師與管理員可從首頁「新增 → 活動」開啟活動表單。學生從首頁查看每秒更新的天、時、分、秒；到期顯示「活動已開始」並保留，直到教師或管理員刪除。活動時間依建立者裝置時區輸入，集中儲存在 PostgreSQL。

公告對象限「學生、教師、全部人員」。學生看不到教師專屬公告，教師與管理員可管理所有公告。原有年級公告轉為學生公告。

## 頁面導覽（v0.10.0）

首頁顯示公告及活動倒數卡片。教師與管理員可在右側「新增」按鈕移入滑鼠或點擊，選擇公告或活動。所有人可在首頁公告區閱讀倒數，屋子圖示返回首頁，「設定」進入獨立設定頁。管理員在設定頁查看表格形式的服務及執行環境狀態；「帳號管理」先顯示人員名單，點「建立人員」才會開啟表單。

## 建立帳號（v0.10.0）

管理員可建立學生、教師及其他管理員；教師可從上方「學生帳號」按「建立學生」，建立學生帳號。一般帳號名稱即可登入，不要求電子郵件，移除姓名及密碼的長度限制，姓名可空白（使用帳號顯示），密碼也可留空。登入帳號仍需填寫且不可重複。教師只能建立與查看學生，修改角色及刪除帳號由管理員處理。

## 帳號編輯與登入狀態（v0.10.0）

建立或編輯人員時可勾選「登入時要求更換密碼」及「停用帳戶」。名單上的「編輯」可修改帳號、姓名、角色（管理員）、登入選項；勾選「重設密碼」才會替換密碼，未勾選則保留。教師可編輯學生，管理員可編輯所有角色。帳號變更後原有登入會失效；停用帳號無法登入。需更換密碼的人員，登入後須確認目前密碼並設定不同的新密碼，完成前不能使用一般功能。既有帳號預設維持啟用且不要求換密碼。


## 公告編輯工作室（v0.12.0）

公告發布頁採寫作區與發布設定側欄。可切換撰寫／閱讀預覽、開啟專注寫作，並查看字數、閱讀時間、自動摘要及標題大綱。分類、對象、置頂與評論開關集中於側欄；手機會自動改成單欄。內容仍須按發布或儲存才會保存至雲端。
