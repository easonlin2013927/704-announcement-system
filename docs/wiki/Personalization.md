# 個人化設定

所有使用者登入後，可由上方「設定 → 個人化」設定自己的外觀。

## 系統風格

提供經典深色、晨光淺色、海洋藍、森林綠、玫瑰粉、暖陽琥珀、午夜靛藍，共 7 種風格。選取時可立即預覽，按「儲存個人化設定」才會保存到帳號。未儲存便離開設定，會恢復原本的風格。

## 暱稱與頭像

暱稱可留空；填寫後會顯示為「原顯示名稱（暱稱）」，原名稱不會被暱稱取代。頭像可上傳 PNG、JPEG、WebP，原圖最多 5 MB；系統會裁成正方形並壓縮。按「移除頭像」後再儲存，會恢復顯示名稱首字。

頭像、暱稱會出現在上方帳號、公告作者與評論。這些設定保存於 PostgreSQL，重新登入或換裝置仍會保留，不使用瀏覽器本機儲存。登入前使用預設風格，登入後套用個人風格。

如圖片無法讀取，請確認格式及檔案大小，重新選圖後儲存。如更換暱稱或頭像，其他使用者重新載入公告及評論後就會看到新資料。
