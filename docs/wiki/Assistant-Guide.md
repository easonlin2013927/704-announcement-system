# 小老師使用手冊

[教師／小老師共用登入入口](https://easonlin2013927.github.io/704-announcement-system/?v=0.13.0#/teacher/login)

小老師是獨立的帳號身分，由管理員在「帳號管理 → 建立人員」選擇「小老師」建立；既有帳號也可由管理員編輯角色。小老師使用教師入口登入，頁首顯示「小老師端」，不會被改成教師身分。

## 可使用的功能

- 閱讀、搜尋公告及查看首頁活動倒數。
- 從「新增 → 公告」進入部落格式編輯器，發布、編輯或刪除公告，設定對象、置頂及自己的公告評論開關。
- 從「新增 → 活動」建立倒數活動，並編輯或刪除活動。
- 設定自己的暱稱、頭像及七種個人風格。

## 權限範圍

小老師不能查看、建立、編輯或刪除任何人員帳號，也不能調整角色。網站標語、跑馬公告及系統管理設定由教師或管理員維護。後端會驗證權限，直接輸入管理 API 網址也不會取得帳號管理權限。

## 常見問題

- **在哪裡登入？** 使用上方教師入口；學生或管理員入口會拒絕小老師帳號。
- **忘記密碼或帳號停用？** 請聯絡管理員，不要在公開 Issues 提供密碼。
- **登入後要求更換密碼？** 先驗證目前密碼，設定不同的新密碼，再使用公告系統。
- **怎麼貼截圖？** 點公告內容區按 Ctrl＋V，或使用「＋圖片」；按發布後才會保存到雲端。
- **沒有帳號管理按鈕？** 這是小老師的權限設定，請由教師或管理員管理人員。
