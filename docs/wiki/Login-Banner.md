# 登入標語設定

教師或維護人員登入後，按右上角「設定」。勾選「啟用標語編輯器與登入標語」後即可編輯。

先選取文字再按粗體、斜體、底線或螢光筆。螢光筆預設黃色，旁邊可選顏色；也支援標題、列表、引用與安全連結。下方預覽會呈現大字顯示效果。

按「儲存設定」才會寫入資料庫。標語公開顯示在三個登入卡片上方，學生不需要登入也能閱讀，所以不要填入個資或密碼。未設定、空白或停用時不顯示標語。

停用後按儲存，登入頁隱藏標語，資料庫保留文字；下次啟用可繼續編輯。清空內容並停用、儲存，才會清掉已儲存標語。取消或離開設定不會自動儲存。

三個入口共用一份標語；教師與維護人員都能更新，以最後儲存的版本為準。已開啟的登入頁可重新整理以取得最新標語。沒有歷史版本或自動草稿。學生不能讀取停用的標語內容，也不能修改設定。

伺服器升級會自動建立 login_banner704 表，不會清空原有公告或標語。備份時也請包含此表。
