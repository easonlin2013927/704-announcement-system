# 教師使用手冊

上方「活動」頁的活動倒數可建立活動名稱及時間（依目前裝置時區輸入），儲存後學生登入即可看見倒數；可編輯或刪除，活動到期後不會自動移除。公告對象已改為「學生、教師、全部人員」。

[前往教師登入](https://easonlin2013927.github.io/704-announcement-system/?v=0.7.0#/teacher/login)

本文件供已取得教師權限的使用者閱讀。教師帳號須由管理員建立，介面切換身分不會取得資料庫寫入權限。

## 登入與權限

使用 README 的「教師登入」獨立連結，輸入管理員提供的電子郵件與密碼。自架版本只有 accounts704 內 role 為 teacher 的帳號能發布、修改或刪除公告。學生即使直接呼叫 API，也無法寫入。

目前所有教師可共同維護全部公告，尚未區分單一公告擁有者。編輯既有公告時，發布者會更新為目前登入教師；原發布日期保留。若需要只讓原作者修改，請管理員調整資料結構與權限規則。

## 撰寫公告

1. 在公告管理首頁展開「新增」，選擇「公告」。
2. 輸入最多 80 字的明確標題。
3. 選擇分類與公告對象。
4. 在公告內容區輸入文字。
5. 視需要啟用置頂。
6. 按「發布公告」，等候成功提示並確認列表出現內容。

標題和內文為必要欄位。公告對象可選學生、教師、全部人員。學生只能看見學生及全部人員公告；教師與管理員可管理全部公告。不要以此發布特定學生的敏感資訊。

## 富文字格式

先選取文字，再按粗體、斜體或底線。清單工具可建立項目符號或編號；段落下拉選單可選一般文字、大標題、小標題或引用。

螢光筆工具可選顏色並標示選取文字。建議只標示截止日期、集合時間及關鍵動作，避免整篇使用螢光筆。

插入連結時先選取文字，輸入以 https:// 或 http:// 開頭的完整網址。發布後請實際開啟確認。貼上的格式可能因安全處理而簡化，腳本、嵌入頁面及不安全屬性會移除。

目前不支援 Word 檔上傳、圖片、附件、表格、字型大小自由設定或協作編輯。可將附件放在學校允許的平台，再加入分享連結並確認學生有閱讀權限。

## 置頂、修改與刪除

置頂公告會顯示在列表前方，多則置頂依發布日期排序；取消置頂不會刪除內容。

使用卡片的編輯按鈕或全文頁「編輯公告」修改，按「儲存變更」後才會寫入雲端。取消或關閉頁面會失去尚未儲存的內容。目前沒有草稿、自動儲存或版本復原，重要文字建議先自行留存。

刪除須確認一次，成功後才從列表移除。目前沒有回收桶。若誤刪，請管理員從事先製作的資料庫備份處理；沒有備份時不保證可復原。

## 保存原則

發布成功的資料保留於 PostgreSQL 資料庫，不依賴教師或學生的本機儲存。系統不設定公告期限、不定時清空，也不在部署時重建資料表。

資料庫專案遭刪除、服務中斷、管理員手動變更或未維護備份仍可能影響資料。請管理員定期備份並確認服務方案及帳單狀態。

## 操作失敗與疑難排解

- 發布失敗：內容保留在目前編輯頁；先複製內文，再確認網路、帳號權限與登入狀態。不要在無成功提示時假設已儲存。
- 請重新登入：登入憑證只存在記憶體，逾期或頁面重新整理後需要登入。先保存未發布文字。
- 重複點擊發布：操作完成前避免重複點擊；若出現重複公告，先確認內容後刪除多餘項目。
- 學生看不到：請學生清空篩選並重新登入。確認發布成功、不是仍停在編輯頁。
- 格式無效果：先選取文字再操作工具；換用更新的 Chrome、Edge、Firefox 或 Safari。瀏覽器對原生富文字工具支援可能略有不同。
- 多人同時修改：目前沒有衝突偵測，後寫入的內容可能覆蓋前一版本。請先協調維護時段。
- 系統尚未設定：由管理員完成雲端設定；不能使用任意示範密碼登入。
- 忘記密碼：請管理員處理，網站沒有自行重設介面。
- 需要協助：到 Issues 選「問題回報」「使用請教」或「網站建議」，不要提交密碼或學生個資。
