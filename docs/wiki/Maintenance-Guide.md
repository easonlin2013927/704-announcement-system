# 維護人員使用說明

[前往維護人員登入](https://easonlin2013927.github.io/704-announcement-system/?v=0.6.0#/admin/login)

請使用維護人員獨立入口，輸入 role 為 admin 的帳號。教師或學生帳號不能登入此入口。

管理員擁有教師的全部公告權限：可新增、編輯、置頂與刪除公告，也能設定登入標語。管理員另有「帳號管理」，可以建立學生、教師與其他管理員、調整帳號角色及刪除帳號。至少須保留一名管理員，且不能刪除目前登入帳號。

「設定」內另有全站跑馬公告。啟用後會顯示於登入頁及登入後頁面的頂端；停用會保留已寫內容。請勿在公開跑馬文字中放置密碼或學生個資。

帳號可在管理員登入後由「帳號管理」建立；初始密碼至少 10 字元，建立後請安全地交付給帳號本人。管理員仍可用主機端 `server/account.mjs` 緊急建立或重設管理員帳號，JSON 的 role 填 admin，切勿把密碼提交至 GitHub。資料庫結構會在新 API 啟動時自動升級，不會清空公告。

重新整理需再次登入；登出或切換入口清除記憶體憑證。資料庫權限、備份、角色變更及密碼重設請依 deploy/README.md 使用主機工具。

登入入口不符會被後端拒絕。刪除帳號會一併撤銷其登入工作階段。若服務失效，先檢查 api704 容器日誌、PostgreSQL 狀態與 Tunnel；不要藉由公開資料庫埠修復。
